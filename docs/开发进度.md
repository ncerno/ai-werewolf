### 修改文件清单

```
src/engine/controller.py    # asyncio.Event 暂停机制, _get_decision/_get_speech 路由
src/server/game_manager.py  # resolve_human_decision, 视角管理, Player 模式随机分配
src/server/websocket.py     # god_decision/player_decision/set_perspective 命令
src/frontend/index.html     # 决策面板 UI + 三种模式启用 + 视角适配 (~1036 行)
```

### 架构要点

- **暂停机制**：`asyncio.Event.clear()` + `await event.wait()` + `resolve_human_decision()` set event，不改变游戏主循环结构
- **决策路由**：`_get_decision()` / `_get_speech()` 根据 mode + human_player_id 自动选择走 LLM 还是等人类
- **God 模式**：所有玩家决策由人类下达，每步暂停等待 WebSocket 输入
- **Player 模式**：人类玩家 ID 随机分配，轮到人类时暂停等待输入，其余走 LLM
- **视角适配**：God → "god"（看全部角色），Player → "player_{id}"（看自己角色+死亡角色），人类死亡后自动切 spectator
- **女巫特殊 UI**：三个按钮（解药/毒药/跳过），选毒药后出现目标选择器，选解药/跳过直接提交
- **前端全量刷新**：每次非 `request_input` 事件都带 `state_snapshot`，全量重绘避免状态不一致
